# 100 Days of Full Stack + DSA

Documenting 100 days of learning full-stack development and data structures & algorithms — building in public, one day at a time.

## About This Challenge

This is **Phase 1** of a longer plan:

- **Phase 1 (current):** 100 days of HTML, CSS, JavaScript, Core Java, and DSA (in C++)
- **Phase 2 (next):** Backend focus, once comfortable with full-stack foundations
- **Phase 3:** Ship 1–2 full-stack projects
- **Phase 4:** Move into GenAI

## Resources / Courses

- **DSA (C++):** [100xDevs](https://harkirat.classx.co.in/) by [Dhruv Parashar](https://x.com/_DhruvPasricha)

## Daily Content

Posted daily under `#100DaysOfCode #FullStackAndDSA`:

- What I learned / built
- Bugs I fixed (and how)
- Weekly recap every Sunday

Also tagged `#LearningInPublic #BuildingInPublic`.

## Repo Structure

```
├── dsa/          → DSA problems, solved in C++
├── frontend/     → Frontend development practice
├── backend/      → Backend development practice
├── progress.md   → daily log: what I did, what I learned
└── README.md     → this file
```

**Naming convention:**

- One file that day → name it directly: `dsa/day05-two-sum.cpp`
- Multiple files that day → use a day subfolder: `dsa/day05/`
- Setup-only days (e.g. Day 0, Day 1) don't get a folder — logged in `progress.md` only
